# Fast GPT

English · [中文](README.zh.md)

A DeepSeek Harness Web plugin that adds an OpenAI-logo button to the composer toolbar. Clicking it opens [ChatGPT](https://chatgpt.com/) in a separate popup window.

## Features

- Sits in the composer toolbar beside the model picker — no extra row.
- Opens a centered 1080×840 popup; later clicks focus that window when the browser allows it.
- Shows an inline notice when the popup is blocked.
- Follows the DSH light/dark theme and ships English and Chinese copy.

## Requirements

- DSH Web with the Conversation UI (tested with `0.2.2-rc.1`)
- Node.js >= 20 and pnpm (build only)

## Install from source

```bash
git clone https://github.com/xqcherry/dsh-fast-gpt.git
cd fast-gpt
pnpm install
pnpm build
dsh plugin --profile web add link:$PWD
```

You can also install this directory from DSH Plugin Manager.

## Usage

Open a session. The OpenAI mark appears in the composer toolbar, left of the model picker. Click it to open ChatGPT in a separate window.

## Configuration

Edit the constants at the top of [`src/client.ts`](src/client.ts):

- `CHATGPT_URL` — default `https://chatgpt.com/`
- `POPUP_WIDTH` / `POPUP_HEIGHT` — default `1080` / `840`, clamped to the screen
- `WINDOW_NAME` — popup window name used for reuse

Rebuild and reload the plugin after changing them.

## Development

```bash
pnpm install
pnpm typecheck
pnpm build
```

`lib/` is generated by TypeScript and is not committed.

## Notes

- Allow popups for the DSH origin, otherwise clicking shows a blocked notice.
- chatgpt.com sends `Cross-Origin-Opener-Policy: same-origin-allow-popups`; the browser may isolate the popup, in which case a later click opens a new window instead of focusing the old one.
- This plugin is not affiliated with OpenAI.
